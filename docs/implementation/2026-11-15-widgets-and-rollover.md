# برنامهٔ اجرای ویجت‌ها و پایداری تغییر روز

اجرای همهٔ موارد طرح در ۲۰۲۶-۱۱-۱۵ تأیید شد. کار تک‌دستیار است. تغییر schema و داده‌های کاربر، کپی مرجع GPL و تغییر ناوبری قفل‌شده خارج از دامنه‌اند. برای حذف نیاز به دستگاه، تست‌های رفتار Android با Robolectric به تست‌های JVM اضافه می‌شوند؛ این شبیه‌سازی تضمین رفتار OEM نیست.

1. مسیر واقعی اعلان و زنگ نیمه‌شب: تست ارسال تاریخ بدون Activity، تغییر روز/ماه، شکست DB و باقی‌ماندن زنگ بعدی؛ اصلاح وابستگی تاریخ به DB و هماهنگی منطقهٔ زمانی. ورودی زمان ثابت و خروجی NotificationManager/AlarmManager است. توقف: آزمون قرمز سپس سبز و compile ماژول scheduler.
2. دادهٔ ویجت: وقوع‌های آینده و هفته/ماه از موتور موجود، با تست موعد گذشته، تکرار، مرز سال و ماه کوتاه. خروجی مدل نمایش است؛ توقف: core:jalali:test.
3. تنظیمات و update: ذخیرهٔ per-ID، حذف/restore، یک snapshot مشترک، خطای قابل تشخیص و ownership coroutine. تست دو نمونه و شکست خواندن. توقف: تست‌های app و compile.
4. رندر سه ویجت موجود و هفته/دستور کار: تنظیمات تم/متن/محتوا، سایزبندی و preview مشترک، ناوبری تاریخ. تست RemoteViews و مقصد Intent؛ توقف: compile و تست‌های Robolectric.
5. مسیر افزودن/پیکربندی و رگرسیون: فهرست preview و پنج نوع، پیکربندی مجدد و حفظ پیش‌نویس. تست cancel/invalid ID و state. توقف: چهار gate پروژه و بررسی diff.
6. مستندات و خروجی: فقط موارد اجراشده به README افزوده شوند؛ test counts از XML محاسبه شوند. build امضاشده بررسی شود؛ انتشار/تست واقعی دستگاه تنها با شواهد مربوط گزارش شود.

مرزهای آزمون همان رفتارهای طرح تأییدشده‌اند: خروجی اعلان و آلارم، تنظیمات عمومی هر نمونه، محتوای قابل مشاهده و Intentهای ویجت، موتور وقوع و بازیابی وضعیت. ابزار تست تنها توسعه‌ای است؛ وابستگی runtime جدید برای UI/زمان‌بندی اضافه نمی‌شود.
